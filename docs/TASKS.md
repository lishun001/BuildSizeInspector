# Codex 开发任务清单

所有任务初始状态均为未完成。本文件描述的是待开发工作，不代表文档编写阶段已经实现平台。

2026-11-18 已实施 M0–M6 本地核心（真实 Jenkins/蒲公英及用户实际工程验收仍未完成）；逐项状态、实际验证命令与缺口见 `IMPLEMENTATION_STATUS.md`，下表继续保留原始任务与验收定义。

先读 `DEVELOPMENT_SPEC.md`，再按依赖顺序实施。每个里程碑都应留下可运行结果、测试和状态记录。不得通过删除失败测试、放宽权限或硬编码演示结果“完成”任务。

## 任务状态约定

使用 `TODO / IN_PROGRESS / DONE / BLOCKED / NOT_VERIFIED`。`DONE` 必须附实际命令、结果和对应变更记录。没有 Unity、Jenkins、Android SDK 或私有项目时，仅将相关外部验证标为 `NOT_VERIFIED`，其他不依赖它们的部分继续实现。

不得把 P1/P2 扩展自动提为 P0。范围变更写 ADR。

目标：建立能持续测试的工程，不先做完整前端。

## M1：离线 APK 分析与比较

依赖 M0-02；分析器应可离线运行，不依赖数据库和 Web。

| ID | 任务 | 产物 | 验收 |
|---|---|---|---|
| M1-01 | ZIP 安全流式读取 | apk_zip analyzer、资源限制 | CRC、重复路径、加密、路径穿越、解压预算测试 |
| M1-02 | 指标与内容 SHA-256 | 规范化快照 | APK 大小恒等式精确成立；不能只用 CRC |
| M1-03 | 物理文件差异 | compare engine、分类器 | 增删改、同长改内容、不同压缩、目录不重复计数 |
| M1-04 | 独立夹具与性质测试 | 合法 ZIP 夹具生成器、Hypothesis 测试 | 反向比较增量取反；随机对账全部通过 |
| M1-05 | 可选 Android 工具适配 | 工具探测、子进程封装 | 可用时记录版本和核验值；不可用时基础分析正常 |

出口：离线输入两个 ZIP/APK，生成准确 JSON 结果。夹具是 ZIP 算法测试，不冒充可安装 APK。

## 必须实现的开发入口

下面是目标工程应实现的统一入口，不是本文档包现有的平台命令：

```bash
make dev
make migrate
make test
make lint
make typecheck
make e2e
make demo
```

`make demo` 必须显著标识演示数据，不允许与真实项目混用。危险输入测试应在受限临时目录中执行。

## 优先修复顺序

数据口径/幂等/权限错误 > 发包影响 > 资源关联错误 > 降级可见性 > 性能 > UI 美化。

如果上下文或执行环境不足，完成当前可验证的最小纵向流程并记录剩余任务；不要一次生成大量互不连通的占位文件。
